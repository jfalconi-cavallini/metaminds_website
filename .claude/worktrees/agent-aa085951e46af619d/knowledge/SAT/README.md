**Skills:** Variables, solving equations, slope, linear functions, systems, inequalities

## Assessment Plan

### Diagnostic Assessment (Session 1)
- 20-question diagnostic covering all 4 math modules
- 15-question R&W diagnostic
- Results map directly to skill gaps
- Determines which modules to prioritize

### Module Assessments
- 10–12 questions at end of each module
- Must achieve 80% before moving to next module
- Retake if below 80% (identify weak skills, reteach)

### Full-Length Practice Tests
- Administered monthly (or every 4 weeks)
- Use official College Board tests (1–8)
- Review wrong answers by skill category
- Track score over time in the Progress tab

## Common Student Struggles (Math)

1. **Systems of equations word problems** — Students can solve algebraic systems but cannot set them up from a paragraph
2. **Percent change vs. percent of** — Confusing "15% more than X" with "15% of X"
3. **Function notation** — f(x+2) does not mean f(x) + 2
4. **Negative exponents** — Especially in exponential functions and scientific notation
5. **Circle problems** — Mixing up arc length, sector area, and chord problems
6. **Reading comprehension** — Selecting the most supported answer vs. the most interesting one
