AP CSP is the introductory college-level CS course. Unlike AP CSA, it is:
- **Language-agnostic** (students can use Python, Snap, Scratch, or any language)
- **Broader in scope** (covers computing in society, not just programming)
- **Project-heavy** (the Create Task is a major component of the score)

AP CSP is the most accessible AP exam for students with limited prior CS experience. It's an excellent gateway course for students exploring CS before committing to AP CSA.

---

## AP CSP Exam Format

| Component | Weight | Description |
|-----------|--------|-------------|
| Create Performance Task | 30% | Build a program with video, written response (done before exam) |
| End-of-Course Exam | 70% | 70 MCQ + 4 written-response questions (3 hours) |

Exam Score: 1–5

---

## Big Ideas (College Board Framework)

AP CSP is organized around 5 Big Ideas:

| Big Idea | % of Exam | Description |
|----------|-----------|-------------|
| Creative Development (CRD) | ~10% | Collaboration, program design, development process |
| Data (DAT) | ~25% | Representation, compression, extraction, privacy |
| Algorithms & Programming (AAP) | ~30% | Variables, control, functions, lists, searching, sorting |
| Computing Systems & Networks (CSN) | ~15% | Internet architecture, packets, protocols, security |
| Impact of Computing (IOC) | ~20% | Legal/ethical issues, digital divide, bias, innovation |

## Create Task: What Students Need to Know

The Create Task is done before the exam. Students must:

1. **Write a program** of their own design (in any approved language)
2. **Record a 1-minute video** of the program running
3. **Submit written responses** to 4 prompts:
   - 3a: Describe the program's purpose
   - 3b: Describe the data used and stored
   - 3c: Explain an algorithm you developed
   - 3d: Identify an abstraction you used

**Common pitfalls:**
- Choosing a project too simple (calculator = automatic low score)
- Not demonstrating a unique algorithm (must not be a library function)
- Not describing abstraction clearly enough in written response

---

## Common Student Struggles

1. **Create Task scope** — Students either pick something too simple or too ambitious
2. **Binary arithmetic** — Two's complement and overflow are confusing
3. **Undecidable problems** — A conceptual topic with no algorithm to practice
4. **Written response clarity** — Technical accuracy + clear writing at the same time
5. **Impact questions on the exam** — These feel like opinion questions but have "correct" answers
6. **Distinguishing lossless from lossy** — And when each matters
