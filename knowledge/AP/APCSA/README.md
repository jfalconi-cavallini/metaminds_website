AP CSA is the rigorous, college-level CS course taught entirely in Java. It covers object-oriented programming, algorithms, and data structures at the introductory CS major level. A 5 on the AP CSA exam typically earns credit for CS1 at most universities.

## FRQ Strategy

AP CSA has 4 Free Response questions. Historically:
1. **Methods & Control Structures** — Writing methods with loops/conditionals
2. **Classes** — Writing a complete class with fields and methods
3. **Array/ArrayList** — Traversal and algorithmic methods
4. **2D Array** — Nested loop traversal

**Key FRQ rules:**
- Write syntactically correct Java (compiler errors lose points)
- Show your imports only if needed (ArrayLists need `java.util.ArrayList`)
- Comments don't substitute for code
- Get partial credit by writing correct sub-methods even if the full method is wrong

## Common Student Struggles

1. **NullPointerException** — Calling a method on a null reference; debugging this
2. **Inheritance confusion** — When to use `super`, when to override, when to call parent methods
3. **Recursion tracing** — Students lose track of the call stack on paper
4. **FRQ writing real Java** — Missing semicolons, wrong method signatures, using wrong types
5. **equals() vs. ==** — This comes up constantly; burn it in early
6. **2D array row/column order** — Students swap row and column in nested loops
