Java is the language of AP Computer Science A (APCSA) and one of the most widely used languages in enterprise software. Students coming from Python transition reasonably well — the core logic is identical, but Java enforces strict typing, compiling, and object-oriented design from the first line.

MetaMinds Java is designed for two audiences:
1. Students preparing for **AP Computer Science A**
2. Students who want **Java for its own sake** (Android development, competitive programming, college CS programs)

---

## Why Java After Python?

| Concept | Python | Java |
|---------|--------|------|
| Typing | Dynamic | Static (strict) |
| Compilation | Interpreted | Compiled (JVM) |
| Syntax | Minimal | Explicit |
| OOP | Optional | Mandatory |
| Error type | Runtime mostly | Compile-time + runtime |
| Use case | Data science, scripting, web | Enterprise, Android, AP CSA |

The biggest shift: Java forces students to understand types and classes from Day 1.

## Common Student Struggles

1. **Semicolons & curly braces** — Python students forget these constantly at first
2. **Static vs. instance** — The distinction between class-level and object-level state
3. **Type errors at compile time** — Python doesn't catch type mismatches until runtime; Java does
4. **NullPointerException** — The most common runtime error; understanding references vs. values
5. **equals() vs. ==** — String comparison using == compares references, not content
6. **Polymorphism** — Abstract thinking about types is the hardest OOP concept to internalize
7. **2D arrays** — Row-column indexing and nested loops together
