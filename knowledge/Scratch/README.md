Scratch is the ideal first programming language for students ages 7–14. Developed at MIT, it uses visual blocks that represent real programming concepts — eliminating syntax errors and letting students focus on logic and creativity. Students who learn Scratch first transition to Python or Java with a massive conceptual head start.

---

## Why Scratch First?

- Zero syntax errors — blocks snap together like LEGO
- Immediate visual feedback — see your program work in real time
- Teaches core concepts: sequences, loops, conditionals, events, variables, functions
- Creative — students build games, stories, animations (motivation is built-in)
- Foundation for every text-based language that follows

## Bridge to Python

After completing Scratch Builder, students understand:
- Variables → same concept in Python, just `score = 0`
- Loops → `for` and `while` loops in Python
- Conditionals → `if/elif/else` in Python
- Functions (custom blocks) → `def` functions in Python
- Events → can understand callbacks and event handlers

First Python lesson for Scratch graduates should explicitly connect these concepts.

## Common Student Struggles

1. **Forgetting to click the Green Flag** — Especially young students; they move blocks but don't run
2. **Infinite loops without a stop condition** — `forever` loops need careful use
3. **Sprite collision** — Understanding the sensing blocks and how touching works
4. **Variable scope** — Not all students realize variables can be global or sprite-specific
5. **Project organization** — Students with many sprites lose track of which code is where
