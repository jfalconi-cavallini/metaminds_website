## Common Student Struggles

1. **Indentation errors** — Python is whitespace-sensitive; beginners forget to indent function bodies
2. **String vs. int type errors** — `input()` always returns a string; forgetting `int(input())` causes crashes
3. **Off-by-one errors** — Especially with range() and list indexing
4. **Mutability** — Lists mutate in place; students expect assignment to copy a list
5. **Scope confusion** — Using a variable defined inside a function outside it
6. **Recursion** — Understanding the base case and call stack takes multiple sessions
